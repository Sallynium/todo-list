# TODO List App

A clean, responsive TODO List built with React + Tailwind CSS.

## Features

- Add / Edit / Delete tasks
- Filter: All / Active / Completed
- Drag & drop to reorder (All mode)
- Clear completed tasks
- Persists via localStorage

## Tech Stack

React 18 · Tailwind CSS · Vite · @hello-pangea/dnd
